# 교내 실습실 PC 원격 이용 서비스 (가칭 JARION Lab Remote) — 구축 계획

## Context
Revit, MIDAS 등은 학교 네트워크 라이선스(라이선스 서버가 학교 IP 대역에서만 응답)로 묶여 있어 학생이 교외에서 쓸 수 없다.
학교 IT팀과 협력하여, **교내 실습실 공용 PC 풀을 원격으로 켜고(Wake-on-LAN), 예약/배정받아, 브라우저로 접속**하는 서비스를 만든다.
소프트웨어는 학교 안 PC에서 실행되므로 라이선스는 학교 IP에서 정상 체크아웃된다(라이선스 우회가 아님).
리포지토리(`JARION`)는 비어 있으므로 신규 구축.

> 사전 확인 필수: Autodesk 교육용 라이선스 / MIDAS 학교 계약서의 "원격 접속 사용" 허용 조항을 IT팀·법무와 확인.
> (대부분 '교내 장비에서 실행 + 재학생 사용'이면 허용되나, 계약별로 다름)

## 전체 아키텍처
```
[학생 브라우저] ──HTTPS──> [웹 포털 (Next.js)] ──API──> [백엔드 (NestJS/FastAPI) + PostgreSQL + Redis]
       │                                                     │
       └──HTTPS/WebSocket──> [Apache Guacamole 게이트웨이] ──RDP──> [실습실 PC (Windows + 에이전트)]
                              (교내 DMZ에 위치)                     │
                                                 [WoL 릴레이 (실습실 VLAN 내부)] ──magic packet──┘
```
- **게이트웨이/백엔드는 학교 DMZ 서버(또는 교내 VM)에 배치** → 외부에는 443 포트 하나만 노출, PC의 RDP(3389)는 절대 외부 미노출.
- 인증: 학교 SSO(SAML/OIDC, 또는 LDAP/AD) + MFA.

## 구성 요소
1. **웹 포털 (Next.js + TypeScript)**
   - 로그인(학교 SSO), PC 현황판(실습실별 가용/사용중/꺼짐), 예약(시간 슬롯), "지금 바로 접속" 버튼
   - 관리자 화면: PC 등록, 강제 종료, 사용 로그, 소프트웨어 설치 현황, 이용 정책(1인 최대 시간 등)
2. **백엔드 API (NestJS 또는 FastAPI) + PostgreSQL**
   - 엔티티: `User`, `Lab`, `Machine`(MAC/IP/사양/설치SW/상태), `Reservation`, `Session`, `AuditLog`
   - 배정 로직: 요청 SW가 설치된 꺼진/유휴 PC 선택 → WoL → 부팅 확인 → Guacamole 연결 생성 → 일회용 토큰 발급
   - 스케줄러: 예약 시작 5분 전 사전 부팅, 종료 10분 전 알림, 종료 시 로그오프+저장 경고, 유휴 N분 후 자동 회수/절전
3. **원격 데스크톱 게이트웨이: Apache Guacamole**
   - 브라우저 HTML5로 RDP 제공, 클라이언트 설치 불필요
   - 백엔드가 Guacamole REST API / JSON auth 확장으로 세션별 연결을 동적으로 생성 (사용자는 PC 계정 비밀번호를 모름)
   - 녹화/클립보드/파일전송 정책을 연결 단위로 제어
4. **PC 에이전트 (Windows 서비스, Go 또는 C#)**
   - 하트비트(온라인·로그인 사용자·CPU/GPU·실행 중 SW) 백엔드로 전송
   - 세션 종료 시 사용자 로그오프, 임시 프로필 정리 / 강제 종료 명령 수신
   - BIOS/NIC에서 WoL 활성화 + Windows 빠른 시작 끄기 (IT팀 GPO로 일괄 적용)
5. **WoL 릴레이**
   - 매직 패킷은 브로드캐스트라 서브넷을 못 넘으므로 실습실 VLAN 내부에 소형 릴레이(라즈베리파이/상시 켜진 PC 1대) 배치, 백엔드가 명령
6. **파일 저장**
   - 학생 작업 파일은 PC 로컬이 아닌 학교 NAS/OneDrive 등 사용자 홈 드라이브로 리다이렉트 (공용 PC라 다음 사용자에게 남지 않도록)

## 성능 고려 (Revit/MIDAS는 3D 작업)
- RDP는 GPU 가속 설정(RemoteFX/AVC444, GPO에서 "하드웨어 그래픽 어댑터 사용") 적용
- Guacamole로 체감이 부족하면 2단계에서 RDP 직접 클라이언트 연결 옵션(RD Gateway 경유) 또는 Parsec/Sunshine 등 저지연 스트리밍 추가 검토

## 보안 체크리스트
- 외부 노출은 포털/게이트웨이 443만, PC는 실습실 VLAN 내부에서 게이트웨이에서 오는 RDP만 허용(방화벽)
- SSO + MFA, 세션 토큰 일회성·단기 만료
- 전 세션 감사 로그(누가/언제/어느 PC), 선택적 화면 녹화
- 클립보드·파일 다운로드 기본 제한(정책으로 조정), 학생 계정은 PC 일반 사용자 권한
- 동시 사용 라이선스 수 초과 방지(백엔드에서 SW별 동시 세션 카운트)

## 단계별 일정 (안)
| 단계 | 기간 | 내용 |
|---|---|---|
| 0. 협의 | 1~2주 | IT팀과 라이선스 조항·네트워크 구조·SSO 방식·파일럿 실습실 확정 |
| 1. PoC | 2주 | PC 3~5대에 WoL 설정, Guacamole 수동 설치·연결, 교외에서 Revit 실행 및 라이선스 체크아웃 확인, 체감 성능 측정 |
| 2. MVP | 4~6주 | 포털(로그인·현황·즉시접속), 백엔드 배정 로직, WoL 릴레이, 에이전트 하트비트/로그오프, 관리자 기본 화면 |
| 3. 파일럿 | 4주 | 실습실 1곳 + 학생 20~50명 대상 운영, 피드백 수집 |
| 4. 확장 | 이후 | 예약 시스템, 사용 통계, 알림(카톡/메일), 다수 실습실, 저지연 스트리밍 옵션 |

## 리포지토리 구조 (모노레포 제안)
```
JARION/
  apps/web/          # Next.js 포털
  apps/api/          # 백엔드 API + 스케줄러
  agent/             # Windows 에이전트 (Go)
  wol-relay/         # WoL 릴레이 (Go/Python)
  infra/             # docker-compose (guacamole, guacd, postgres, redis, api, web), nginx/TLS
  docs/              # 아키텍처, IT팀 설정 가이드(GPO, 방화벽, BIOS WoL)
```

## 검증 방법
- PoC: 교외 네트워크(모바일 핫스팟)에서 포털 접속 → PC 자동 부팅 → 브라우저 RDP 접속 → Revit/MIDAS 실행 및 라이선스 정상 확인
- MVP: docker-compose로 로컬 통합 실행, 백엔드 배정/스케줄러 단위 테스트, 테스트용 Windows VM 2대로 E2E(예약→부팅→접속→자동 회수)
- 파일럿: 동시 접속 수·지연시간·부팅 실패율·라이선스 초과 건수 모니터링
