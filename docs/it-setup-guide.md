# 실습실 PC 설정 가이드 (IT팀용) — JARION 원격 접속 PoC

학생이 학교 밖에서 **실습실 PC를 원격으로 켜고(Wake-on-LAN) 브라우저로 접속**해 Revit·MIDAS 등 학교 라이선스 프로그램을 쓰기 위한 PC·네트워크 설정입니다.
프로그램은 교내 PC에서 실행되므로 라이선스는 지금처럼 학교 IP에서 체크아웃됩니다.

> **사전 확인:** Autodesk 교육용 라이선스·MIDAS 학교 계약의 원격 접속 사용 허용 여부를 법무/구매 담당과 확인해 주세요.

---

## 1. 네트워크 / 방화벽

| # | 출발지 | 목적지 | 포트 | 용도 |
|---|---|---|---|---|
| N1 | 인터넷 | 게이트웨이 서버 (DMZ) | TCP 443 (+80 리다이렉트) | 학생 브라우저 접속 |
| N2 | 게이트웨이 서버 | 실습실 VLAN | TCP 3389 | RDP |
| N3 | WoL 릴레이 | 실습실 VLAN 브로드캐스트 | UDP 9 | 원격 켜기 |
| N4 | 관리자 PC | 게이트웨이 서버 | TCP 22 | 서버 관리 (교내망에서만) |
| N5 | 실습실 PC | 게이트웨이 서버 | TCP 443 | PC 에이전트 상태 보고 (2단계) |

- 실습실 PC의 3389 포트는 **절대 인터넷에 직접 열지 않습니다.** (각 PC 방화벽에서도 게이트웨이 IP만 허용 — 3장 스크립트가 설정)
- **WoL 릴레이:** 매직 패킷은 브로드캐스트라 라우터를 넘지 못합니다. 실습실 VLAN 안에 상시 켜진 장비 1대(라즈베리파이 또는 강사용 PC)를 두고 `tools/wol/wol.py` 를 실행합니다.
  - 대안: 스위치/라우터에서 directed broadcast(`ip directed-broadcast`) 를 게이트웨이 서버 출발지로만 허용 — 보안상 릴레이 방식을 권장합니다.
- 스위치: PC가 꺼져 있어도 포트 링크가 유지되어야 합니다 (스위치 포트 절전/EEE 기능은 끄는 것을 권장).
- PC IP는 **DHCP 예약(고정)** 으로 지정해 주세요. 게이트웨이에 IP로 등록합니다.

## 2. BIOS / UEFI 설정 (PC 마다, 수동)

메뉴 이름은 제조사마다 다릅니다. 아래 키워드로 찾으세요.

| 설정 | 값 | 제조사별 이름 예시 |
|---|---|---|
| Wake-on-LAN | **Enabled** | Wake on LAN / Power On By PCI-E / Resume by LAN / Remote Wake Up |
| Deep Sleep / ErP / EuP | **Disabled** | Deep Sleep Control (Dell), ErP Ready (ASUS·Gigabyte), S5 Max Power Savings (HP) |
| 정전 후 동작 (선택) | Power On 또는 Last State | AC Recovery / Restore on AC Power Loss |
| 부팅 순서 | 내부 디스크 우선 | (PXE 부팅으로 빠지지 않도록) |

- 제조사 관리 도구로 일괄 적용 가능: **Dell Command | Configure**, **HP BIOS Configuration Utility**, **Lenovo Think BIOS Config Tool**.
- BIOS 관리자 비밀번호 설정 권장.

## 3. Windows 설정 (스크립트)

`scripts/windows/Setup-LabPC.ps1` 을 **관리자 PowerShell** 에서 실행합니다.

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
```
```powershell
.\Setup-LabPC.ps1 -GatewayIP 10.0.5.20 -RemoteUsers "SCHOOL\LabRemoteUsers" -OutputCsv \\nas\it\jarion\lab-pc.csv
```
바꾸기 전에 할 일만 확인하려면 `-WhatIf` 를 붙입니다.

스크립트가 하는 일:

| # | 설정 | 이유 |
|---|---|---|
| 1 | RDP 켜기 + NLA 필수 | 원격 접속, 로그인 전 인증 |
| 2 | 기본 RDP 방화벽 규칙 끄고 게이트웨이 IP만 3389 허용 | 교내 다른 PC/외부에서의 직접 접속 차단 |
| 3 | 빠른 시작·최대 절전 끄기, AC 절전 60분 | 빠른 시작이 켜져 있으면 종료 상태에서 WoL 이 안 되는 경우가 많음 |
| 4 | 랜카드 "매직 패킷으로 깨우기" 등 WoL 속성 활성화 | WoL |
| 5 | 원격 세션 하드웨어 GPU 사용 정책 | 미적용 시 Revit 3D 뷰가 소프트웨어 렌더링으로 매우 느려짐 |
| 6 | 원격 사용자 그룹 등록 | 학생 계정의 RDP 로그인 허용 |
| 7 | PC 이름·MAC·IP·GPU·설치 SW 를 CSV 로 저장 | 게이트웨이 등록용 |

### 스크립트로 못 하는 랜카드 항목 (장치 관리자 → 네트워크 어댑터 → 속성)
- **전원 관리** 탭: "전원을 절약하기 위해 컴퓨터가 이 장치를 끌 수 있음" 체크, "이 장치가 컴퓨터의 대기 모드를 해제할 수 있음" 체크, "매직 패킷에서만…" 체크
- **고급** 탭: `Shutdown Wake-On-Lan` / `Wake on Magic Packet` = 사용, `Green Ethernet` / `Energy Efficient Ethernet` / `절전 모드에서 속도 낮추기` = 사용 안 함 (링크가 끊겨 WoL 실패 원인)

## 4. 그룹 정책(GPO)으로 일괄 적용 (도메인 환경 권장)

실습실 PC OU 에 GPO 하나를 만들어 적용하면 스크립트 1·2·5·6 을 대체할 수 있습니다.

| 경로 | 정책 | 값 |
|---|---|---|
| 컴퓨터 구성 > 관리 템플릿 > Windows 구성 요소 > 원격 데스크톱 서비스 > 원격 데스크톱 세션 호스트 > 연결 | 사용자가 원격 데스크톱 서비스를 사용하여 원격으로 연결할 수 있도록 허용 | 사용 |
| … > 세션 호스트 > 보안 | 네트워크 수준 인증을 사용한 사용자 인증 필요 | 사용 |
| … > 세션 호스트 > 원격 세션 환경 | 모든 원격 데스크톱 서비스 세션에 하드웨어 기본 그래픽 어댑터 사용 | 사용 |
| … > 세션 호스트 > 원격 세션 환경 | 원격 데스크톱 연결에 H.264/AVC 444 그래픽 모드 우선 순위 지정 | 사용 |
| … > 세션 호스트 > 원격 세션 환경 | 원격 데스크톱 연결에 H.264/AVC 하드웨어 인코딩 구성 | 사용 |
| … > 세션 호스트 > 세션 시간 제한 | 활성 상태이지만 유휴 상태인 원격 데스크톱 서비스 세션에 대한 시간 제한 설정 | 2시간 (PoC 값, 운영 정책과 협의) |
| … > 세션 호스트 > 세션 시간 제한 | 연결이 끊어진 세션에 대한 시간 제한 설정 | 30분 |
| … > 세션 호스트 > 연결 | 원격 데스크톱 서비스 사용자를 단일 원격 데스크톱 서비스 세션으로 제한 | 사용 |
| 컴퓨터 구성 > 기본 설정 > 제어판 설정 > 로컬 사용자 및 그룹 | Remote Desktop Users 에 `LabRemoteUsers` 추가 | |
| 컴퓨터 구성 > 정책 > Windows 설정 > 보안 설정 > 고급 보안이 포함된 Windows Defender 방화벽 | 인바운드 TCP 3389, 원격 주소 = 게이트웨이 IP | 허용 |

### 공용 PC 이므로 추가 권장
- **폴더 리디렉션**: 문서·바탕화면 → 학생 홈 드라이브(NAS) — 다음 사용자에게 파일이 남지 않도록
- 학생 계정은 **일반 사용자 권한** (로컬 관리자 아님)
- 로그오프 시 로컬 프로필 삭제 정책 (또는 "지정한 일 수보다 오래된 사용자 프로필 삭제")
- 현장 사용자와 원격 사용자가 겹치지 않도록, PoC 기간에는 **원격 전용 PC 3~5대를 지정**하고 책상에 안내문 부착

## 5. 계정

| 단계 | 방식 |
|---|---|
| PoC | Guacamole 에는 연결만 등록, 학생은 Windows 로그인 시 **본인 학교(AD) 계정** 입력. 테스트 학생은 `LabRemoteUsers` 그룹에 추가 |
| 2단계 | 학교 SSO(SAML/OIDC) 또는 LDAP 를 포털·Guacamole 에 연동, 2단계 인증 적용 |

## 6. 확인 절차 (PC 1대씩)

1. 스크립트 실행 후 **재부팅**
2. 교내 다른 PC 에서 RDP 접속이 **거부**되는지 확인 (게이트웨이만 허용되었는지)
3. 게이트웨이(Guacamole)에서 접속 → 로그인 → Revit 실행 → 작업관리자 성능 탭에서 **GPU 사용률이 오르는지** 확인
4. **시작 → 전원 → 시스템 종료** (완전 종료)
5. 같은 VLAN 의 릴레이에서:
   ```bash
   python3 tools/wol/wol.py <MAC> --broadcast <실습실 브로드캐스트 주소>
   ```
6. 1~2분 내 부팅되면 성공. 실패 시 아래 점검.

### WoL 실패 시 점검 순서
1. BIOS: Deep Sleep / ErP 가 꺼져 있는가 (가장 흔한 원인)
2. PC 가 꺼진 상태에서 랜 포트 LED 가 켜져 있는가 (꺼져 있으면 BIOS/랜카드 절전 문제)
3. 빠른 시작이 꺼져 있는가 (`powercfg /a` 에 "빠른 시작" 사용 불가로 나와야 함)
4. 브로드캐스트 주소가 맞는가 / 릴레이가 같은 VLAN 인가 / UDP 9 대신 7 시도 (`--port 7`)
5. 스위치 포트 절전(EEE) 끄기, 랜카드 드라이버를 제조사 최신 버전으로 업데이트

## 7. PC 에이전트 설치 (2단계)

포털이 반납·만료 시 원격 세션을 로그오프하고, PC 앞에 앉은 사람이 있으면 원격 배정하지 않도록 하는 Windows 서비스입니다. 자세한 내용은 [agent/README.md](../agent/README.md).

1. 개발팀에서 받은 `jarion-agent.exe`, `Install-JarionAgent.ps1`, 등록 키를 IT 공유 폴더에 둡니다 (등록 키 파일은 관리자만 읽기).
2. GPO: 컴퓨터 구성 > 정책 > Windows 설정 > 스크립트 > **시작** 에 PowerShell 스크립트로 추가
   ```
   Install-JarionAgent.ps1 -Source \\nas\it\jarion\jarion-agent.exe -ApiUrl https://remote.<학교도메인> -EnrollmentKey <등록 키>
   ```
   같은 버전이면 아무것도 하지 않으므로 매 부팅 실행해도 됩니다. 새 버전은 공유 폴더의 exe 만 바꾸면 다음 부팅 때 반영됩니다.
3. 포털 관리 화면 → PC 탭에서 **에이전트: 정상** 확인
4. IT 관리자가 원격으로 점검할 때 쓰는 계정은 포털 `.env` 의 `AGENT_EXEMPT_USERS` 에 넣어 주세요. 넣지 않으면 포털 배정 없이 접속한 원격 세션으로 보고 로그오프됩니다.
